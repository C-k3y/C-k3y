# 👋 Hi I'm Kelsey
<h3 align="center">Developer in progress. Builder by curiosity.</h3>

## 🧑‍💻 A Little About Me

I'm an aspiring Software Engineer who enjoys turning ideas into things that actually work.

I started with frontend development, building interfaces and bringing ideas to life on the web. Somewhere along the way, I got curious about what happens beyond the screen.How applications work behind the scenes, how blockchains operate, and how different technologies fit together. That curiosity led me into Web3, smart contracts, and blockchain development.

I'm currently learning backend development and working toward understanding the bigger picture: how to build applications from the interface to the systems powering them.
I'm still learning, still experimenting, and occasionally breaking things just to understand how to fix them. That's part of the process.

Beyond building applications, I'm curious about smart contract security, cryptography, Zero-Knowledge Proofs, and how decentralized systems can solve real-world problems.

**I don't have everything figured out. I'm here to build, learn, and get better.**
